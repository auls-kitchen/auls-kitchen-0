Category Diagnostic — READ ONLY

Temporary utility for Scope 1B live data inspection. This page performs Firestore reads only (getDocs on "products" and "categories", plus a targeted getDoc on status/soldOut and on a single product by ID for Scope 1B.2) — no setDoc, updateDoc, addDoc, deleteDoc, arrayUnion/arrayRemove, or batch writes exist anywhere in this file. It does not touch transactions, purchases, expenses, or any other collection, and it does not modify the production Admin, POS, Online Menu, or Customer Display files. Delete this file after Scope 1B is finished — it is not meant to be a permanent feature.

⚠️ READ-ONLY DIAGNOSTIC. This tool cannot and does not write, delete, or migrate anything. If anything here looks wrong, do not "fix" it manually from this page — report it back for an explicit decision.
