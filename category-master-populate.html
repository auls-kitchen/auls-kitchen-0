Category Master Population — Scope 1C

One-time-use utility. Writes ONLY to categories/coffee, categories/milky, categories/soda, categories/blend, categories/tea, categories/cooler, categories/choco — nothing else. Every one of those 7 documents is read first; a matching existing document is left completely untouched (no rewrite, no timestamp change); a missing document is created; a conflicting existing document is reported and NOT written. No product document, no blueelectric, and no other collection is ever written to. Delete this file after Scope 1C is verified — it is not a permanent feature.

⚠️ This is the first tool in this project that performs real Firestore writes. It will ask for explicit confirmation before writing anything, and only after showing you exactly what it found.
Allowed writes: setDoc on categories/{coffee, milky, soda, blend, tea, cooler, choco} — new documents only, using {label, categoryOrder, createdAt, updatedAt}. No updateDoc, no deleteDoc, no arrayUnion/arrayRemove, no writes to any product, no writes to categories/blueelectric.
